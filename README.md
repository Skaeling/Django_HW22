<h2>Web store on Django</h2>
Проект представляет собой Интернет-магазин игрушек.

В текущей сборке пользователю доступны для просмотра 3 HTML-страницы: Главная, Контакты, и индивидуальная страница товара.
<br>Реализован переход между имеющимися страницами по соответствующим кнопкам меню навигации, возможность отправки обратной связи со страницы Contacts, создания нового продукта с сохранением данных в БД. 
<br>Для стилизации страниц использован наборы Bootstrap JS и СSS, установленные в проект.


<h3>Для корректной работы программы необходимо:</h3> 
1. Установить зависимости, указанные в файле requirements.txt<br/>
2. Для подключения к БД создать файл .env в корне проекта, заполнить его в соотвествии с шаблоном .env.sample<br/>


<h3>Краткое описание работы программы:</h3> 
Проект написан на фреймворке Django, осуществляет подключение к локальному серверу, рендеринг страниц в соотвествии с запросом. СУБД - Postgresql.
