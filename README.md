<h2>Web store on Django</h2>
Проект представляет собой Интернет-магазин игрушек.

<br>В текущей сборке пользователю доступны для просмотра: 
<br>3 HTML-страницы приложения Catalog: Главная, Контакты, и детальная страница товара.
<br>2 cтраницы приложения Blog: Блог, детальная страница поста. Доступны функции создания, редактирования, удаления постов.
<br><br/>Реализован переход между имеющимися страницами по соответствующим кнопкам меню навигации, возможность отправки обратной связи со страницы Contacts, создания нового продукта/поста с сохранением данных в БД. 
<br>Для стилизации страниц использован наборы Bootstrap JS и СSS, установленные в проект.


<h3>Для корректной работы программы необходимо:</h3> 
1. Установить зависимости, указанные в файле requirements.txt<br>
2. Для подключения к БД создать файл .env в корне проекта, заполнить его в соотвествии с шаблоном .env.sample<br>
3. Для активации функции отправки письма по достижению Х просмотров статьи(по умолчанию 100) - внести параметры SMTP-сервера в .env.sample<br>


<h3>Краткое описание работы программы:</h3> 
Проект написан на фреймворке Django, осуществляет подключение к локальному серверу, рендеринг страниц в соотвествии с запросом. СУБД - Postgresql.
