<h2>Web store on Django</h2>
Проект представляет собой Интернет-магазин.

В текущей сборке пользователю доступны для просмотра 2 HTML-страницы: Home и Contacts.
<br>Реализован переход между имеющимися страницами по соответствующим кнопкам меню навигации и возможность отправки обратной связи со страницы Contacts. 
<br>Для стилизации страниц использован наборы Bootstrap JS и СSS, установленные в проект.

<h3>Для корректной работы программы необходимо:</h3> 
Установить зависимости, указанные в файле requirements.txt<br/>

<h3>Краткое описание работы программы:</h3> 
Проект написан на фреймворке Django, осуществляет подключение к локальному серверу, рендеринг страниц в соотвествии с запросом.
